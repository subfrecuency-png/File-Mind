Privacy and telemetry

What stays on your Mac

Everything, by default: the index, content hashes, extracted text, the embedding model and its vectors, the transaction journal, the audit log and the database itself. The database is encrypted with SQLCipher; the key is a random 32-byte value in your login Keychain (ai.filemind). FileMind makes no network requests at all unless you enable one of the three things below.

1. AI adapters (off by default)

Ask sends a question plus context to the adapter you chose: file names, folders, dates and at most 2 KB of extracted text from the top hits. Never a whole file, never a path outside your chosen folders, never a file classified as sensitive (keys, .env, card or ID numbers). Every call is logged with adapter, model, purpose, byte count, latency and whether it left the machine. The text is not stored — only its size and a hash.

2. Update checks (on)

Settings → Updates fetches a small signed manifest from GitHub Releases when you press Check. It contains version numbers and download URLs; the request carries no identifier.

3. Telemetry (off by default, aggregate only)

If you switch it on in Settings, once a day the app sends one JSON document to the FileMind telemetry endpoint. The full schema lives in the repository at docs/TELEMETRY.md and is checked by a test; this is all of it:

No paths, no names, no content, no hashes of any of them, no IP retention on the receiving side beyond the request log's 24 hours.

Crash reports (you choose to send)

If the agent or the app panics, a report is written to ~/Library/Logs/FileMind/crashes/: version, OS, the panic message and a stack trace with paths under your home folder replaced by ~. Nothing is sent automatically. Settings → Feedback shows pending reports and lets you review one and send it.

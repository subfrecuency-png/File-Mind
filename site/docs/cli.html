CLI reference

The filemind binary ships inside the app bundle (FileMind.app/Contents/MacOS/filemind); add it to your PATH or symlink it. When the agent is running, commands go through it; otherwise they work on the database directly.

filemind status                  # database, mode, roots, counts
filemind roots add ~/Downloads   # register a folder
filemind scan                    # read-only metadata scan
filemind hash --minutes 5        # content hashes, throttled
filemind search "offer sheet from last spring"
filemind ask "which supplier quoted the lowest price per ton?"
filemind note add ~/x.pdf "the one we accepted"
filemind analyze                 # duplicates, versions, health, suggestions
filemind health · dupes · versions · projects
filemind suggest · suggest plan 12 · suggest apply 12
filemind history · undo txn_…
filemind mode observe|assist|automate
filemind rule kinds|add|preview|arm|pause|rm|runs|tick
filemind agent install|uninstall|start|stop|status
filemind model status|download
filemind ai status|set …
filemind dev db-key              # the SQLCipher key for the sqlcipher shell

Every command has --help. Output that goes to a pipe (| head) ends cleanly.

Changelog

Unreleased

  • Shrink estimate: filemind shrink estimate and the Overview “Shrinkable” tile measure, by sampling and compressing a few KB per file, what APFS compression, lossless JPEG XL/PNG and cold-project archives could reclaim.
  • Shrink tier 1: Shrink suggestions compress cold text, code and raw-format files in place with APFS transparent compression — a journaled Rewrite step that is read back and hash-checked before it counts, survives a crash at any point, and undoes in place. filemind shrink info <path> shows a file's on-disk state.
  • Recovery runs before every plan, apply and undo, not only at agent start — a transaction another process left unfinished is settled instead of blocking with “recover it first”.
  • Shrink tier 3: Archive suggestions pack a cold project into one compressed file under ~/FileMind Archive — content-defined chunks deduplicated across archives, zstd with dictionaries trained on your own files, every member decoded and hash-checked before the original folder goes to Trash. Search still finds every file inside (with a Restore button); filemind archive list|show|verify|restore.

0.2.0 — beta 1

  • Signed, notarized macOS app with the agent and CLI bundled; Start at login; in-app updates.
  • Automate mode with the seven-day preview, three tier-0 rule kinds, pause on conflict.
  • Database encrypted at rest (SQLCipher, key in Keychain).
  • Whole-folder duplicate suggestions; Put back for trashed items; menu-bar health score.
  • Background jobs with progress for scan, analysis, embedding and the model download.
  • Opt-in aggregate telemetry, local crash reports, in-app feedback.

0.1.0 — private alpha

  • Scanner, index, health score, duplicates and versions, projects, classification, search by meaning, Ask, transactions with undo, desktop app.

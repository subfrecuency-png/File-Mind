Getting started

FileMind is a menu-bar app for macOS 14 and newer with a background agent and a command-line tool. Everything runs on your Mac; the only thing it writes outside the folders you choose is its own database in ~/Library/Application Support/FileMind/.

Install

Download the .dmg from the beta invite, drag FileMind to Applications and open it. The first launch asks for the folders you want indexed — Downloads, Documents, Desktop and Pictures are suggested — and which mode to start in. Observe is the default: it indexes and suggests, and never moves a file.

The app bundles the agent and the filemind CLI. Settings → Background agent → Start at login registers the agent with launchd so it keeps the index current while you are logged in.

The first hour

The agent scans metadata first (fast), then hashes contents at a throttled pace, then classifies files and extracts text for search. On a 190,000-file home folder the scan takes about a minute; hashing and classification run in the background at roughly a fifth of one core. The Overview shows progress and a health score that sharpens as the index fills in.

Search index

Search works from the first scan on names and paths. Search by meaning needs the local embedding model (bge-small, 133 MB): Settings → Search index → Download model. It is fetched once from Hugging Face and never sent anywhere.

Where things live

WhatWhere
Database (encrypted)~/Library/Application Support/FileMind/filemind.db
Database keyLogin Keychain, item ai.filemind
Embedding model~/Library/Application Support/FileMind/models/
Agent logs~/Library/Logs/FileMind/agent.log
Archived downloads~/FileMind Archive/ (only if you apply that suggestion)
Login item~/Library/LaunchAgents/ai.filemind.agent.plist

Uninstall

Settings → Background agent → turn off Start at login, quit from the menu bar, move FileMind.app to the Trash, and delete the folder above if you want the index gone. Nothing else is touched; anything FileMind moved is still where History says it is, or in your Trash.

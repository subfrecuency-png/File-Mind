Search and Ask

Type the way you would describe a file to a colleague: the offer sheet for the calcium supplier from last spring, pdf. FileMind parses the parts it can (kinds, dates, seasons, sizes, “in downloads”, “in project X”) into filters and matches the rest by words and by meaning, then fuses the two rankings. When the filters leave nothing, it retries without them and tells you so.

Words vs meaning

Lexical search covers names, paths and extracted text (FTS5). Semantic search embeds each file from its name, folder words, category and the first 2 KB of text with bge-small-en-v1.5, locally. The toggle in the search bar lets you see each side alone.

Notes

“the one we accepted, signed in May” — attach a note to any file or folder from a search hit. Notes are indexed both ways and show up as their own results.

Ask

⌘Enter turns the query into a question answered over the top hits by the adapter you chose in Settings: none (the default), Ollama on your Mac, or the Anthropic API. The answer lists its sources; the footer shows how many bytes were sent. Every call is recorded in the audit log with the adapter, model, purpose and size — never the text.

Ollama can serve hosted models (names ending in :cloud). FileMind labels those calls CLOUD in the audit log because the context leaves your machine even though Ollama itself is local.
